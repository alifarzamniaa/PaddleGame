# Paddle Game Project
Destroy boxes with a moving ball and a paddle and dont let the ball fall.

this project is kinda inspired from arkanoid.

## How to install
This project is made entirely in SFML, so you need to clone this project and then download SFML and install it.

**Installing SFML Guide :** 

https://www.sfml-dev.org/tutorials/3.0/

## What I learned
In this project, I learned how the math behind this works and when to use Dot Product and when to not too (because I just learned what it was). So for simple movements like this, I didn't have to use it and just simply calculate where the ball hit and react based on that was enough. And I kinda learned to refactor more and don't use unnecessary functions and classes.
